# How to Use This Site

This site is an interactive roadmap for preparing for system design interviews, compiled from:

- [Hello Interview — System Design in a Hurry](https://www.hellointerview.com/learn/system-design/in-a-hurry/introduction)
- [Gaurav Sen — System Design Playlist](https://www.youtube.com/playlist?list=PLMCXHnjXnTnvo6alSjVkgxV-VH6EPyvoX)
- [InterviewReady by Gaurav Sen](https://interviewready.io/course-page/system-design-course)
- [Hello Interview YouTube](https://www.youtube.com/@hello_interview/playlists)

## The Roadmap (Home Page)

The **[Roadmap](/)** is the main page. It shows all 35 topics organized into three difficulty levels:

| Level | Topics | Focus |
|-------|--------|-------|
| Level 1 — Foundational | 8 topics | Appear in every interview |
| Level 2 — Intermediate | 16 topics | Differentiate mid-to-senior candidates |
| Level 3 — Advanced | 11 topics | Staff+ level interviews |

### How to use the roadmap:

1. **Work top to bottom** — Level 1 before Level 2, Level 2 before Level 3
2. **Click a topic card** to expand it and see the description, resource links, and which problems cover it
3. **Check the checkbox** when you feel confident in a topic — progress saves automatically in your browser
4. **Use the search bar** to quickly find a topic by name or technology
5. **Use the filter tabs** to focus on one difficulty level at a time

## Topics Section

The **Topics** sidebar (this section) has a full reference page per topic, with:
- What to learn and key concepts
- Direct resource links (Hello Interview articles + YouTube videos)
- List of interview problems that test this topic

## Problems Section

The **Problems** sidebar has a page per interview problem, with:
- Difficulty rating
- What the problem tests
- Topics it covers (so you know what to study first)
- Direct link to the Hello Interview breakdown

## Suggested Study Path

```
Week 1–2   → Learn + practice Level 1 topics (Bitly, Dropbox, Yelp)
Week 3–5   → Level 2 topics (WhatsApp, YouTube, Rate Limiter, Instagram)
Week 6–8   → Level 3 topics (Uber, Google Docs, Ad Aggregator)
```

Start each topic by reading the Hello Interview article, watch the relevant Gaurav Sen video, then attempt the easiest problem that covers it before moving to harder ones.
