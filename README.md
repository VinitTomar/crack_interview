# Buzz Interview

A structured, self-hosted study guide for cracking software engineering interviews.

## Topics Covered

**High-Level Design (HLD)**
- 35 topics: Caching, CDN, Kafka, Redis, Sharding, Rate Limiting, etc.
- 29 system design problems: YouTube, WhatsApp, Uber, Dropbox, etc.

**Low-Level Design (LLD)**
- 16 topics: OOP, SOLID, Design Patterns (GoF), Concurrency, etc.
- 8 OO design problems: Parking Lot, LRU Cache, Ride Sharing, etc.
